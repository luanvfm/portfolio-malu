- `maria-luiza-sem-fundo.png`: recorte com transparência, 1135 × 1386.
- `maria-luiza-800.webp`: versão para o site, 800 × 977.
- `maria-luiza-480.webp`: versão leve, 480 × 586.

As versões WebP foram codificadas pela API Canvas do navegador preservando a transparência. O navegador escolhe a versão conforme a largura e a densidade da tela.
